# Project Lab

A project-focused portfolio for software systems, practical tools, and experimental AI hardware.

**Website:** https://ponderwith.me/

## Featured projects

- [SW Exchange](https://github.com/Bowen-Wang-dev/SW-Exchange) — simulated exchange, matching, wallets, and ledgers.
- [Currency Exchange Cost Calculator](https://github.com/Bowen-Wang-dev/Currency-exchange-cost-calculator) — CNY → HKD → AUD route cost calculations.
- [Codex Companion Controller](https://github.com/Bowen-Wang-dev/codex-companion-controller) — experimental ESP32-C3 hardware companion and Mac Bridge.
- [Codex Pager 4G](https://github.com/Bowen-Wang-dev/codex-pager-4g) — concept and planning for a portable AI notification device.

## Site

The complete site lives in `index.html`: responsive layout, category filters, accessible project-detail dialogs, and an illustrative controller interaction. No build step, package installation, account connection, or API credentials are required.

Serve the repository root with any static web server for local preview. On GitHub Pages, use the `main` branch and repository root (`/`). The existing `CNAME` retains `ponderwith.me` as the custom domain.

Project details are a snapshot of the linked repositories on 2026-10-31. Update cards and the `projects` object in `index.html` when project milestones change. Graphics are conceptual illustrations, not live application or device state.
